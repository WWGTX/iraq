# مدونة الأحكام الشرعية في مسائل الأحوال الشخصية (المذهب الجعفري)

موقع ثابت (بدون خادم) يعرض نص المدونة كاملاً (337 مادة + قرار المصادقة) مع بحث ذكي وملف PDF الأصلي.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub (Public).
2. ارفع كل الملفات: `index.html` و`data.js` و`code.pdf` و`.nojekyll`.
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقة يظهر الرابط: `https://USERNAME.github.io/REPO/`

## مزايا البحث
- يتجاهل التشكيل والهمزات والتاء المربوطة/الهاء والألف المقصورة.
- يتجاهل الفراغات الزائدة داخل الكلمات (مشكلة نص الـPDF الأصلي).
- بحث بعدة كلمات (AND) ثم نتائج جزئية تلقائياً، وعبارة دقيقة بين علامتي تنصيص.
- مطابقة تقريبية عند الأخطاء الإملائية، ومرادفات (ميراث/إرث، مهر/صداق، خلع/فدية...).
- كتابة رقم مادة (مثل 136) تنقلك لها مباشرة، وروابط المواد داخل النصوص قابلة للضغط.
- حفظ مواد مفضلة، نسخ، رابط مباشر لكل مادة، فتح الصفحة المقابلة في PDF، وضع ليلي، تكبير الخط.

> ملاحظة: النص مستخرج آلياً من طبقة النص في الـPDF وقد تبقى فيه فراغات بسيطة داخل بعض الكلمات؛ الملف الأصلي مرفق للرجوع إليه.
